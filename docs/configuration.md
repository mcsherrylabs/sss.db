## Basic Configuration

### application.conf Structure

sss.db uses Typesafe Config (HOCON format) for configuration:

```hocon
database {
  datasource {
    driver = "org.postgresql.Driver"
    connection = "jdbc:postgresql://localhost:5432/mydb"
    user = "myuser"
    pass = "mypassword"
    maxPoolSize = 20
  }

  viewCachesSize = 100
  useShutdownHook = true
  freeBlobsEarly = false
}
```

### Loading Configuration

```scala
// Load "database" config from application.conf
val db = Db("database")

// Load custom named config
val reportsDb = Db("reportsDatabase")
```

### Database Drivers

**PostgreSQL:**
```hocon
datasource {
  driver = "org.postgresql.Driver"
  connection = "jdbc:postgresql://localhost:5432/mydb"
}
```

**MySQL:**
```hocon
datasource {
  driver = "com.mysql.cj.jdbc.Driver"
  connection = "jdbc:mysql://localhost:3306/mydb"
}
```

**HSQLDB (for testing):**
```hocon
datasource {
  driver = "org.hsqldb.jdbc.JDBCDriver"
  connection = "jdbc:hsqldb:mem:test"  # In-memory
  # OR
  connection = "jdbc:hsqldb:file:./data/mydb"  # File-based
}
```

### Initial SQL Execution

Run SQL on database startup:

```hocon
database {
  datasource { /* ... */ }

  # SQL to run before anything else (optional)
  deleteSql = [
    "DROP TABLE IF EXISTS old_table",
    "DROP VIEW IF EXISTS old_view"
  ]

  # SQL to run on startup (optional)
  createSql = [
    """CREATE TABLE IF NOT EXISTS users (
         id BIGINT GENERATED BY DEFAULT AS IDENTITY,
         name VARCHAR(256),
         email VARCHAR(256),
         PRIMARY KEY(id)
       )""",

    """CREATE INDEX IF NOT EXISTS idx_users_email 
       ON users(email)"""
  ]
}
```

## Security

### Environment Variables

⚠️ **Never commit credentials to version control!**

```hocon
database {
  datasource {
    driver = "org.postgresql.Driver"
    connection = ${DATABASE_URL}      # From environment
    user = ${DATABASE_USER}           # From environment  
    pass = ${DATABASE_PASSWORD}       # From environment
    maxPoolSize = 20
  }
}
```

**Setting environment variables:**

```bash
# Development
export DATABASE_URL="jdbc:postgresql://localhost:5432/mydb"
export DATABASE_USER="dev_user"
export DATABASE_PASSWORD="dev_password"

# Production (use secrets management)
export DATABASE_URL="jdbc:postgresql://prod-db:5432/prod"
export DATABASE_USER="prod_user"
export DATABASE_PASSWORD="${SECRET_FROM_VAULT}"
```

**Optional variables:**

```hocon
# Use ${?VAR} for optional values (won't fail if missing)
database {
  datasource {
    connection = ${?DATABASE_URL}
    user = ${?DATABASE_USER}
    pass = ${?DATABASE_PASSWORD}
  }
}
```

### Separate Configurations

**Development:**
```hocon
# dev.conf
include "application.conf"

database {
  datasource {
    connection = "jdbc:postgresql://localhost:5432/dev_db"
    user = "dev_user"
    pass = "dev_pass"
  }
}
```

**Production:**
```hocon
# prod.conf
include "application.conf"

database {
  datasource {
    connection = ${DATABASE_URL}
    user = ${DATABASE_USER}
    pass = ${DATABASE_PASSWORD}
    maxPoolSize = 50  # Higher for production
  }

  useShutdownHook = false  # Managed by container
}
```

**Load specific config:**
```scala
// Development
val db = Db("database", ConfigFactory.load("dev"))

// Production  
val db = Db("database", ConfigFactory.load("prod"))
```

## Connection Pool Tuning

sss.db uses HikariCP for connection pooling.

### Pool Size Configuration

```hocon
datasource {
  # Maximum number of connections in pool
  maxPoolSize = 20

  # Minimum number of idle connections maintained
  minimumIdle = 5
}
```

**Sizing formulas:**

**For SyncRunContext:**
```
maxPoolSize = expected_concurrent_transactions + buffer
Example: 50 concurrent requests → maxPoolSize = 55
```

**For AsyncRunContext:**
```
maxPoolSize = num_cpu_cores * 2
Example: 8-core machine → maxPoolSize = 16
```

### Timeout Configuration

```hocon
datasource {
  # Wait time for connection from pool (ms)
  connectionTimeout = 30000  # 30 seconds

  # Idle connection lifetime (ms)  
  idleTimeout = 600000  # 10 minutes

  # Maximum connection lifetime (ms)
  maxLifetime = 1800000  # 30 minutes
}
```

### Performance Optimizations

```hocon
datasource {
  # Prepared statement caching
  cachePrepStmts = true
  prepStmtCacheSize = 250
  prepStmtCacheSqlLimit = 2048

  # Use server-side prepared statements
  useServerPrepStmts = true

  # Connection properties (PostgreSQL example)
  connectionProperties = "stringtype=unspecified"
}
```

### Transaction Isolation

```hocon
datasource {
  # Set default isolation level
  transactionIsolationLevel = "TRANSACTION_READ_COMMITTED"
  # Options:
  # - TRANSACTION_NONE
  # - TRANSACTION_READ_UNCOMMITTED
  # - TRANSACTION_READ_COMMITTED (default)
  # - TRANSACTION_REPEATABLE_READ
  # - TRANSACTION_SERIALIZABLE
}
```

## Advanced Settings

### viewCachesSize

Caches View metadata (column names/types):

```hocon
viewCachesSize = 100  # Default

# Increase if you have many distinct queries (>100 unique View objects)
viewCachesSize = 500  # For apps with 500+ different queries
```

**When to increase:**
- Application creates many View instances dynamically
- Many different table/view names accessed
- High query variety

**Memory impact:** ~1KB per cached View (minimal)

### useShutdownHook

Registers JVM shutdown hook to close connections:

```hocon
useShutdownHook = true   # Default - register hook

useShutdownHook = false  # Don't register (manual lifecycle management)
```

**Set false when:**
- Managing lifecycle manually
- Using container shutdown hooks (Kubernetes, Docker)
- Application framework handles cleanup (Play, Akka)

### freeBlobsEarly

Releases blob memory immediately after extraction:

```hocon
freeBlobsEarly = false  # Default - normal cleanup

freeBlobsEarly = true   # Release blob memory immediately
```

**Enable when:**
- Working with large blobs (>10MB)
- Memory-constrained environments  
- High blob throughput

**Trade-off:** Small performance overhead for memory savings

## Multiple Databases

### Separate Configurations

```hocon
# Primary database
primaryDb {
  datasource {
    driver = "org.postgresql.Driver"
    connection = "jdbc:postgresql://localhost:5432/primary"
    user = "primary_user"
    pass = "primary_pass"
    maxPoolSize = 30
  }
}

# Analytics database (read-only)
analyticsDb {
  datasource {
    driver = "org.postgresql.Driver"
    connection = "jdbc:postgresql://analytics-host:5432/analytics"
    user = "analytics_reader"
    pass = "analytics_pass"
    maxPoolSize = 10
  }

  viewCachesSize = 200  # More diverse queries
}
```

### Using Multiple Databases

```scala
// Initialize both databases
val primaryDb = Db("primaryDb")
val analyticsDb = Db("analyticsDb")

// Use primary for writes
val userTable = primaryDb.table("users")
userTable.persist(Map("name" -> "Alice")).runSyncAndGet

// Use analytics for reads
val analyticsView = analyticsDb.view("user_stats")
val stats = analyticsView.findAll().runSyncAndGet
```

### Cross-Database Transactions

⚠️ **Not supported** - each Db manages its own connection pool. Transactions don't span databases.

```scala
// ❌ Won't work - separate transactions
val transaction = for {
  user <- primaryDb.table("users").persist(Map("name" -> "Alice"))
  _ <- analyticsDb.table("user_log").insert(Map("user_id" -> user.id))
} yield user
// These use different connections/transactions!

// ✅ Handle at application level
val user = primaryDb.table("users").persist(Map("name" -> "Alice")).runSyncAndGet
try {
  analyticsDb.table("user_log").insert(Map("user_id" -> user.id)).runSyncAndGet
} catch {
  case e: Exception =>
    // Compensating transaction
    primaryDb.table("users").delete(where(ps"id = ${user.id}")).runSyncAndGet
    throw e
}
```

## Example Configurations

### Development (Local)

```hocon
database {
  datasource {
    driver = "org.hsqldb.jdbc.JDBCDriver"
    connection = "jdbc:hsqldb:file:./data/dev"
    user = "SA"
    pass = ""
    maxPoolSize = 5
  }

  viewCachesSize = 50
  useShutdownHook = true
  freeBlobsEarly = false

  createSql = [
    "CREATE TABLE IF NOT EXISTS users (...)"
  ]
}
```

```hocon
database {
  datasource {
    driver = "org.postgresql.Driver"
    connection = ${DATABASE_URL}
    user = ${DATABASE_USER}
    pass = ${DATABASE_PASSWORD}

    maxPoolSize = 50
    minimumIdle = 10

    connectionTimeout = 30000
    idleTimeout = 600000
    maxLifetime = 1800000

    cachePrepStmts = true
    prepStmtCacheSize = 250
    prepStmtCacheSqlLimit = 2048
    useServerPrepStmts = true
  }

  viewCachesSize = 200
  useShutdownHook = false
  freeBlobsEarly = false
}
```

testDb {

## Summary

**Security:**
- Use environment variables for credentials
- Never commit passwords to version control
- Separate dev/staging/prod configurations

**Pool Sizing:**
- Sync: maxPoolSize = concurrent_transactions + buffer
- Async: maxPoolSize = num_cpu_cores * 2

**Timeouts:**
- connectionTimeout: 30 seconds
- idleTimeout: 10 minutes
- maxLifetime: 30 minutes

**Caching:**
- Enable prepared statement caching
- Increase viewCachesSize for query-heavy apps

**Multiple Databases:**
- Separate config blocks
- No cross-database transactions
- Handle at application level
